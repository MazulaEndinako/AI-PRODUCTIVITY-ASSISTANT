# Work Buddy AI

Build the AI Workplace Productivity Assistant: a modern, responsive SaaS dashboard with sidebar navigation. Include five core tools: 1) Smart Email Generator with tone selection (formal, friendly, persuasive), 2) Meeting Notes Summarizer extracting action items, decisions, and deadlines, 3) AI Task Planner / Scheduler with daily and weekly views and task prioritization, 4) AI Research Assistant for topic and article summaries with insights, and 5) Interactive AI Chatbot interface. Provide structured input and editable output panels, copy/export actions, clean metrics on the dashboard overview, and a responsible AI disclaimer.
